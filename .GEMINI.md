# Gemini Context and Rules

## Project Overview
This repository contains spatial clustering approaches designed to optimize clustering for skewed datasets: 
- **Grid-Based Clustering** and **Grid-Based Density Clustering** (`structures/grid.py`)
- **R-Tree Spatial Analyzer** (`structures/r_tree_analyzer.py`)

The algorithms are implemented in Python and are intended for research and thesis work focused on improving clustering performance and overlap minimization in spatially skewed data.

## Environment & Package Management (STRICT RULES)
- **Virtual Environments**: Always use `virtualenv` for managing Python environments. 
  - To create: `virtualenv .venv`
  - To activate: `source .venv/bin/activate`
- **Package Installation**: **CRITICAL:** Always use `uv pip install` instead of standard `pip install` when adding, installing, or modifying packages. For example, use `uv pip install -r requirements.txt`.

## Directory Structure
- `structures/`: Contains the core clustering algorithms and data structures.

## Experimental Architecture & Codebase Logic
- **Fair Comparisons (k-Groups Constraint)**: Grid and R-Tree are forced to output exactly $k$ clusters (so they match K-Means benchmarks) via an `enforce_k_groups(k)` post-processing step. This merges adjacent spatial groupings using `sklearn.cluster.AgglomerativeClustering` (average linkage).
- **R-Tree Initialization**: The R-Tree (`structures/r_tree_analyzer.py`) is bulk-loaded efficiently using the **STR (Sort-Tile-Recursive)** algorithm by feeding a generator (`stream_data()`) directly to `rtree.index.Index()`.
- **Dataset Scaling**: Robust large-scale datasets (up to 100k points) of various geographic layouts (skewed vs. normal) can be instantly generated using `utils/generate_large_datasets.py`.
- **Multi-Run Benchmarks (`main.py`)**: To combat spatial MAUP (Modifiable Areal Unit Problem) boundary bias and non-determinism, each algorithm is executed iteratively (e.g. 10 to 100 runs).
  - *Grid*: Jitters the `xmin, ymin` starting boundaries continuously per run.
  - *R-Tree*: Implements micro-variance noise (e.g. `1e-8`) to points upon load to affect STR sort order subtly.
  - Only the run producing the **minimum overlap area** is retained as the final benchmark score.
- **Memory Management (`CRITICAL`)**: When running the evaluation loop in `main.py`, the stateful OOP structure `Geometry.all` inside `structures/geometry.py` MUST be wiped using `Geometry.clear_all()` before each Grid run to prevent colossal RAM memory leaks. Memory profiling (`psutil`) is active.
- **Outputs**: Numerical comparisons output to `experiment_results.csv`. Overlap visualization scatter plots are automatically rendered and saved locally to `images/run-expirement/` appending their exact origin dataset and $k$ scaling value.
- **Documentation**: A detailed rationale for technique choices is maintained in `ARCHITECTURE_DECISIONS.md`.
